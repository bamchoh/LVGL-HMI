Preset icons of Tsukuraku (tools/icons/gen_icons.py draws them).

  <size>/<name>.png    size: 24, 32, 48, 64 (px)    names: icons.txt    all of them: preview.png

White on a transparent background. On a screen, give them a color with the style "image_recolor":
  { "type": "image", "src": "assets/icons/48/motor.png", "style": { "image_recolor": "#36c98f" } }
